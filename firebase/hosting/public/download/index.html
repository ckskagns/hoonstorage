앱 내려받기 (APK) 설치했어요 · 초대 링크로 돌아가기
  1. 위 버튼으로 uridul.apk를 내려받아요.
  2. 다운로드 알림이나 내 파일 → 다운로드에서 파일을 눌러요.
  3. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아와 설치를 눌러요.
  4. 갤럭시에서 설치가 막히면 설정 → 보안 및 개인정보 보호 → 자동 차단을 잠시 꺼 주세요. 설치 후 다시 켜도 돼요.
  5. 설치가 끝나면 받은 초대 링크를 다시 눌러 연결해요.
