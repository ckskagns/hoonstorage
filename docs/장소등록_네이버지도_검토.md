# 일정별 장소 등록 (네이버 지도 연동) 검토 (2026-10-27)

요청 예시: 27일 일정 — **18:30 저녁식사 → 네이버 지도 "선릉감자탕" 등록(선택)**, 등록된 장소를 누르면 네이버 지도 앱이 열림

## 결론

**개발 가능.** 네이버 지도 앱이 제공하는 앱 연동 주소(URL Scheme)와 **"공유하기"** 를 이용하면, 별도 API 키·서버·비용 없이 구현할 수 있다. 예상 개발 기간 2~3일.

## 동작 방식 (권장안)

1. 일정 추가·수정 화면에 **장소** 줄이 생긴다: `📍 장소 (선택)  [네이버 지도에서 찾기]`
2. **네이버 지도에서 찾기** → 네이버 지도 앱이 열리고 검색어(장소 칸에 쓴 말, 없으면 일정 제목)로 바로 검색
3. 네이버 지도에서 가게를 고르고 **공유 → 우리둘** 을 누르면, 우리둘로 돌아와 장소 칸에 **가게 이름 + 네이버 지도 링크** 가 자동으로 채워짐
   - 장소 이름만 직접 써도 된다 (링크 없이)
4. 일정 카드·상세에 `📍 선릉감자탕` 표시 → **누르면 네이버 지도 앱에서 그 장소가 열림**
   - 링크가 있으면 그 장소 페이지, 이름만 있으면 그 이름으로 검색
   - 네이버 지도 앱이 없으면 네이버 지도 웹(브라우저)으로 열고, 설치 안내
5. 상대가 등록한 장소도 똑같이 보이고 눌러서 열 수 있다 (일정과 함께 서버에 저장되므로)

## "시간별 장소" 를 어떻게 담을지

| 방식 | 설명 | 판단 |
|---|---|---|
| **A. 일정 하나 = 장소 하나** | 지금 일정에 이미 시간이 있으므로 "18:30 저녁식사" 일정에 장소 하나를 붙인다. 하루에 여러 곳이면 일정을 여러 개 등록 | **1단계로 권장** (화면이 단순, 달력·알림과 그대로 연결) |
| B. 일정 안에 코스(세부 일정) | 일정 하나 안에 `18:30 저녁식사 📍선릉감자탕`, `20:00 카페 📍○○카페` 처럼 시간별 줄을 여러 개 | 2단계 확장 (데이트 코스·여행 일정에 유용) |

A 로 시작해도 B 로 넓힐 때 데이터가 그대로 이어지도록 저장 형식을 잡는다.

- 저장 형식(예정): 일정 문서에 `place: { name, link }` (B 확장 시 `stops: [{ time, title, place }]`)
- 30분 전 알림에도 장소를 함께 표시: "30분 뒤 일정이 있어요 · 18:30 저녁식사 📍선릉감자탕"

## 검토 항목

### 기능 구현
- 네이버 지도 앱 연동 주소: `nmap://search?query=선릉감자탕&appname=com.uridul.app` (검색), `nmap://place?lat=…&lng=…&name=…&appname=…` (좌표 표시). `appname` 에 우리 앱 패키지 이름을 넣는 것이 필수.
- 공유 받기: 우리둘을 안드로이드 **공유 대상**으로 등록 → 네이버 지도의 공유 내용(가게 이름, 주소, `naver.me` 링크)을 받아서 이름과 링크를 뽑아낸다. 일정 입력 창이 열린 상태로 돌아와 장소 칸만 채운다.
- 안드로이드 11 이상은 다른 앱 설치 여부를 확인하려면 매니페스트에 네이버 지도 앱(`com.nhn.android.nmap`)을 선언해야 한다.
- 보안 규칙: 일정 저장 규칙에 `place` 항목을 허용하도록 추가 (길이 제한 포함).

### 비용·키
- 권장안은 **API 키가 필요 없고 무료**다 (네이버 지도 앱이 검색·장소 페이지를 모두 담당).
- 앱 안에서 바로 장소를 검색하려면 네이버 검색(지역) API 가 필요하다. 하지만 2026-07-31 이후 새 키는 **NAVER API HUB 종량제**로 발급되고, 비밀 키를 앱에 넣으면 공개된 APK 에서 꺼내질 수 있다. 서버(유료 요금제)를 거쳐야 안전하므로 이번 범위에서는 **비권장**.
- 앱 안에 지도를 그려 보여주는 것(네이버 지도 SDK)도 가능하지만 네이버 클라우드 가입·키 발급이 필요해 나중 단계로 둔다.

### 개인정보
- 장소는 가게 이름과 링크만 저장하고, 내 현재 위치는 쓰지 않는다 (위치 권한 불필요).
- 일정과 같은 보안 규칙으로 두 사람만 볼 수 있다.

### 기타
- 공유 내용 형식은 네이버 지도 버전에 따라 조금 다를 수 있어, 링크(`naver.me`·`map.naver.com`)를 찾는 방식으로 넓게 처리하고, 못 찾으면 첫 줄을 이름으로 쓴다.
- 장소 링크는 시간이 지나 가게가 없어지면 열리지 않을 수 있다 → 이름으로 검색하는 버튼을 함께 둔다.
- 카카오맵·T맵도 같은 방식으로 붙일 수 있다 (필요하면 선택 메뉴).

## 진행 제안
1. A 방식(일정당 장소 하나) + 네이버 지도 검색 열기 + 공유로 채우기 + 눌러서 열기 (2~3일)
2. 필요하면 B 방식(코스) 확장
