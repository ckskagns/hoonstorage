# 일정 사진첩: 완전 무료 요금제(Spark) 검토

> 작성일: 2026-10-28 · 조건: 카드 등록 없는 Firebase 무료 요금제(Spark) 그대로, 추가 비용 0원
> 이전 검토: [사진 기능 도입 검토](사진기능_도입검토.md)

## 1. 먼저 확인한 사실

| 항목 | 내용 |
|---|---|
| Firebase 사진 저장소(Cloud Storage) | **무료 요금제에서는 더 이상 쓸 수 없음.** 2024-10 부터 새 저장소는 유료(Blaze) 요금제 필요, 2026년 현재 무료 요금제 프로젝트는 저장소 접근 자체가 막힘 (402·403 오류) |
| 구글 포토 연동(API) | 2025-03-31 부터 공유 앨범 기능이 API 에서 빠지고, 앱이 직접 올린 사진만 다룰 수 있게 바뀜 → 두 사람 앨범을 앱이 만들고 관리하는 방식은 불가 |
| Firestore (지금 쓰는 데이터 저장소) | 무료 요금제로 **저장 1GiB · 읽기 하루 5만 · 쓰기 하루 2만**. 문서 하나 최대 1MiB → **줄인 사진은 문서에 직접 넣을 수 있음** |

## 2. 무료로 가능한 방법

| | 방법 | 사진 화질 | 우리둘 안에서 보기 | 용량 | 비고 |
|---|---|---|---|---|---|
| **A** | **Firestore 에 줄인 사진 저장** | 긴 변 1280px (폰 화면으로 보기 충분) | ○ 바로 보임 (추억 슬라이드·일정 카드) | 1GiB ≈ 사진 4,000~6,000장 | 원본은 아님 |
| **B** | **구글 포토 공유 앨범 링크 붙이기** | 원본 | △ 누르면 구글 포토 앱이 열림 | 각자 구글 계정 15GB 안에서 | 지금 장소(지도 링크)와 같은 방식, API 없음 |
| C | 각자 폰에만 저장 (지금 사진 위젯 방식) | 원본 | 내 폰에서만 | 폰 용량 | 상대에게는 안 보임 → 사진첩으로는 부족 |
| D | Firebase 저장소 (유료 요금제) | 원본 | ○ | 무료 사용량 있음 | **카드 등록 필요 → 완전 무료 조건에 안 맞음** |
| E | 외부 무료 이미지 사이트 (Imgur 등) | 다양 | ○ | 다양 | 커플 사진을 외부 서비스에 올려야 해서 사생활·약관 문제 → 추천 안 함 |

### A. Firestore 에 줄인 사진 저장 (자세히)

- 올리는 법: 일정 카드·하루 페이지에서 **📷 사진 더하기** → 폰 사진 고르기 → 앱이 크기를 줄여 저장
  - 보기용: 긴 변 1280px, JPEG 품질 75 → 장당 약 150~250KB (문서 하나에 한 장)
  - 목록용 작은 그림: 긴 변 320px → 장당 약 20KB (목록·슬라이드는 이것만 받아서 빠르고 아낌)
- 저장 위치: `couples/{id}/photos/{사진ID}` (일정 ID·날짜·누가 올렸는지·작은 그림), 큰 그림은 `photoData/{사진ID}` 에 따로
- 두 사람만 읽고 쓰기 (보안 규칙), 지운 사진은 바로 사라짐
- **용량 계산** (데이트 주 2번 × 사진 4장 가정)
  - 1년 약 400장 × (200KB + 20KB) ≈ **연 90MB** → 1GiB 로 **약 10년**
  - 읽기: 슬라이드 20장 + 사진 몇 장 크게 보기 = 하루 수십 번 → 한도 5만의 1% 미만
  - 폰에 한 번 받은 사진은 저장해 두어(Firestore 캐시) 다시 볼 때 데이터가 거의 안 듦
- 한계: 원본이 아님(인쇄·확대용으로는 부족), 일정 하나에 사진 수 제한 권장(예: 10장)

### B. 구글 포토 공유 앨범 링크 (자세히)

- 구글 포토 앱에서 앨범 만들기 → **링크 공유** → 공유 대상에서 **우리둘** 선택 → 그 일정에 "📷 앨범" 태그가 붙음
- 태그를 누르면 구글 포토 앱에서 그 앨범이 열림 (원본, 동영상도 가능)
- 앱이 할 일은 링크 저장·열기뿐이라 API·비용 없음 (지금 지도 장소 붙이기와 똑같은 구조)
- 한계: 우리둘 화면 안에 사진이 바로 보이지는 않음, 두 사람 모두 구글 포토 사용 필요

## 3. 추천: A + B 함께

| 용도 | 방법 |
|---|---|
| 일정마다 **대표 사진 몇 장** (추억 슬라이드·일정 카드에 바로 보이게) | **A. 줄인 사진을 Firestore 에** (일정당 최대 10장) |
| 그날 찍은 **사진 전부·원본·동영상** | **B. 구글 포토 공유 앨범 링크를 일정에** |

- 비용 0원, 카드 등록 없음, 지금 무료 요금제 그대로
- 홈의 **지난 한 달 추억 슬라이드**가 그림 대신 그 날 대표 사진으로 바뀜 (사진이 없으면 지금처럼 그림 카드)
- 개발 순서·난이도
  1. B 앨범 링크 붙이기 — 반나절 (장소 공유와 같은 구조)
  2. A 사진 더하기·보기·지우기 + 슬라이드 연결 — 2~3일
  3. 백업 파일에 사진 포함 여부 결정 (파일이 커지므로 "사진 빼고 저장" 기본 권장)
