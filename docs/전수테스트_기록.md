# 전수테스트 기록

"전수테스트 진행해" 를 받으면 아래 순서로 진행하고, 회차마다 결과를 여기에 적는다.

1. 코드 리클러스터링 — 큰 파일 나누기, 중복 합치기, 역할별 정리 (동작은 그대로)
2. 속도·처리 효율 개선 — 불필요한 서버 읽기·반복 계산·다시 그리기 줄이기
3. 버그 확인 — 최근 바뀐 코드부터 다시 읽고 고치기 (+ lint 검사)
4. 기능 테스트 — 단위 테스트 → 에뮬레이터(S26 Ultra 환경) → 폴드8 실기기(서버 저장까지). 테스트 데이터는 "test0…" 이름으로 만들고 끝나면 지움
5. 결과 기록·커밋 (배포는 따로 요청할 때만)
