# AI 비서 준비 가이드 (제미나이 Pro 크레딧 + Firebase 무료 유지)

우리둘 AI 비서는 **제미나이 API**(클라우드)를 쓰고, 요금은 제미나이 Pro 구독에 들어 있는
**매달 $10 구글 클라우드 크레딧**으로 냅니다. Firebase(rabbithooni-5d8f4)는 무료 요금제 그대로 둡니다.

> ⚠️ 가장 중요한 것: **결제 계정을 Firebase 프로젝트(rabbithooni-5d8f4)에 연결하지 마세요.**
> 연결하는 순간 Firebase 가 종량제(Blaze)로 바뀝니다. 제미나이용 **새 프로젝트**에만 연결합니다.

> 🔑 API 키는 채팅·카톡·메모 앱에 붙여 넣지 마세요. 키는 나중에 우리둘 앱의 "AI 키 넣기" 화면에
> 직접 넣고, 우리 두 사람만 읽을 수 있는 서버 칸에 저장됩니다. 키를 잊어도 AI Studio 에서 다시 볼 수 있습니다.

---

## 1. Pro 크레딧 받기 (구글 개발자 프로그램)

Pro 구독 중인 구글 계정으로 진행합니다.

1. https://me.developers.google.com/benefits 를 엽니다. 처음이면 개발자 프로필을 만들라고 나옵니다 (이름만 넣으면 됨).
2. 혜택 목록에서 **Google Cloud 크레딧(월 $10)** 을 찾습니다.
3. 결제 계정을 고르라고 나옵니다.
   - 결제 계정이 없으면 https://console.cloud.google.com/billing 에서 **결제 계정 만들기** → 카드 등록.
     (크레딧을 넘게 쓴 금액만 카드로 청구됩니다. 아래 5번 예산 알림으로 지킵니다.)
4. 결제 계정을 고르고 **"항상 이 결제 계정 사용"** 을 체크한 뒤 신청합니다 → 다음 달부터 자동으로 들어옴.
5. 확인: 결제 계정 → **크레딧** 메뉴에 $10 크레딧이 보이면 성공.
   - 매달 받은 크레딧은 받은 날부터 1년 동안 쓸 수 있습니다.

## 2. 제미나이용 새 프로젝트 만들기

1. https://console.cloud.google.com/projectcreate
2. 프로젝트 이름: **uridul-ai** (다른 이름도 괜찮음) → 만들기.
   - 예전에 만든 빈 프로젝트 `uridul-couple-2706` 이 남아 있으면 그걸 써도 됩니다.
3. 왼쪽 메뉴 **결제** → 1번의 결제 계정(크레딧 있는 것)을 이 프로젝트에 **연결**.

## 3. 제미나이 API 키 만들기

1. https://aistudio.google.com/apikey
2. **API 키 만들기** → 프로젝트 고르기에서 **uridul-ai** 선택 → 만들기.
3. 키 이름 옆에 요금제가 **유료(Paid / Tier 1)** 로 보이면 크레딧 결제가 연결된 것입니다.
   - "무료(Free)" 로 보이면 2-3번(결제 연결)을 다시 확인하세요.

## 4. 키 제한 걸기 (잃어버려도 남이 못 쓰게)

1. https://console.cloud.google.com/apis/credentials (위쪽에서 프로젝트 **uridul-ai** 선택)
2. 방금 만든 키 이름을 누릅니다.
3. **애플리케이션 제한사항** → **Android 앱** → 항목 추가:
   - 패키지 이름: `com.uridul.app`
   - SHA-1 인증서 지문: `5E:1A:27:8E:E7:8C:48:BF:AB:E2:3B:3D:3A:DD:1D:3E:0C:D3:11:51`
     (우리둘 앱 서명값 — 비밀번호가 아니라 공개돼도 괜찮은 값)
4. **API 제한사항** → **키 제한** → **Generative Language API** 만 체크.
5. 저장.

## 5. 예산 알림 + 하루 상한

1. https://console.cloud.google.com/billing → 결제 계정 → **예산 및 알림** → 예산 만들기
   - 범위: 프로젝트 uridul-ai, 금액: **$10** (원화 계정이면 약 14,000원)
   - 알림: 50% · 90% · 100% → 메일로 옴
   - 예산은 "알림" 만 하고 자동으로 멈추지는 않습니다 → 아래 하루 상한으로 막습니다.
2. https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com/quotas (프로젝트 uridul-ai)
   - 하루 요청 수(Requests per day) 항목을 찾아 **500** 정도로 낮춥니다 (두 사람이 쓰기에 충분).

## 6. (나중에) 청약 공식 일정

청약 기능을 만들 때 진행합니다.
1. https://www.data.go.kr 회원가입
2. "한국부동산원 청약홈 분양정보 조회 서비스" 검색 → **활용신청** → 인증키 발급 (보통 바로 또는 1~2시간)
