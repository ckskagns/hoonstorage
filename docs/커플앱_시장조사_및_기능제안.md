## 2. 리뷰에서 만족하는 기능 (우선순위)

| 순위 | 만족 포인트 | 대표 앱 | 리뷰에서 나온 이유 |
|---|---|---|---|
| 1 | **매일 질문·답하기** | 썸원, 기억 나무, 커플 다이어리 | 대화가 자연스럽게 늘고 서로 더 알게 됨 |
| 2 | **귀여운 캐릭터·디자인 위젯** | Ourday, 기억 나무, 커플 다이어리 | "캐릭터를 위젯에 두니 항상 같이 있는 기분" |
| 3 | **공유 캘린더·할 일** | 시그널링, 러블 | 둘의 일정 관리가 편함 |
| 4 | **기록(스토리·일기·사진)** | The Couple, 럽다, 비트윈 | 추억이 쌓이는 재미 |
| 5 | 커플 게임·미션 | 러브마블, LovBirdz, Lovify | 승부욕, 새로운 질문 |
| 6 | 꾸미기·키우기(나무, 펫) | 기억 나무, 썸원 | 매일 들어오게 만드는 재미 |

**리뷰의 개선 요청 (우리둘이 바로 반영할 만한 것)**
- 시그널링: **음력 날짜 입력**(부모님 생신), **색깔별 일정 분류**(데이트/업무/개인), 공유 가계부, **폴드8에서 위젯 글씨가 너무 작음**
- 러블: **반복 할 일**(매일 약 챙기기), 일정 장소 주소 검색
- 기억 나무: 캘린더 위젯에서 상세 내용 보기
- 럽다: 사진 순서 바꾸기, 수정 중 내용 날아가지 않게

**리뷰의 불만 (우리둘이 피해야 할 것)**
- 광고·결제 유도 과다 (썸원, Couple2, Lovify)
- **데이터 유실** (비트윈 사진 대량 삭제, The Couple 연결 해제 후 기록 소실)
- 알림 지연·누락 (비트윈), 위치 공유 부정확·배터리 (Love8)
- 고객센터 부재

## 3. 우리둘 추가 기능 제안

판단 기준: ① 리뷰 만족도 ② 우리둘에 적용 가능한지 (현재 무료 요금제 · 서버 함수 없이 · 두 사람 전용) ③ 폴드8/S26 Ultra 화면

### 바로 적용 추천 (무료 요금제로 가능)

| 우선 | 기능 | 내용 | 난이도 |
|---|---|---|---|
| ★1 | **오늘의 질문** | 하루 한 질문, 둘 다 답해야 서로의 답이 열림. 질문 300개는 앱에 내장 | 중 |
| ★2 | **음력 기념일·일정** | 부모님 생신 등 음력 반복 (안드로이드 내장 음력 달력 사용) | 중 |
| ★3 | **기념일 알림** | 100일·주년·생일 하루 전/당일 알림 (폰 안에서 예약, 서버 불필요) | 하 |
| ★4 | **일정 카테고리 색** | 데이트·여행·기념일·개인 등 색 지정 | 하 |
| ★5 | **공유 할 일·버킷리스트** | 반복 할 일(매일 약), 같이 하고 싶은 것 체크 | 중 |
| ★6 | **데이터 백업 내보내기** | 일정·기록을 파일로 저장. 연결이 끊겨도 데이터는 지우지 않음 | 하 |
| ★7 | **캐릭터 꾸미기** (이번에 기본 적용) | 후이(아기 용)·나나(토끼) 캐릭터를 홈·캘린더·위젯에 | 진행 중 |
| ★8 | 오늘의 기분 | 이모지로 기분 공유, 위젯에 상대 기분 표시 | 하 |

### 검토 후 적용 (조건 있음)

| 기능 | 조건 |
|---|---|
| 사진 추억 앨범 | Firebase 사진 저장소(Storage)는 유료(Blaze) 요금제 필요. 작은 사진만 Firestore에 넣는 방식은 무료로 가능 |
| 콕 찌르기·상대 활동 즉시 알림 | 상대 폰에 알림을 보내려면 서버 함수(유료 요금제) 필요. 사용량이 적어 실제 요금은 거의 0원 수준 |
| 교환일기 | 무료로 가능. 오늘의 질문 다음 단계로 추천 |
| 커플 게임·밸런스 질문 | 무료로 가능. 질문 콘텐츠가 충분해야 반복 불만이 없음 |

### 추천하지 않음
- **실시간 위치 공유**: 배터리 소모·부정확 불만이 가장 많고 사생활 부담이 큼
- **채팅**: 카카오톡으로 충분하고, 알림 지연 불만이 많음
- **광고·유료 기능**: 두 사람 전용 앱이라 불필요

## 4. 제안 순서
1. 이번 작업: 이름(후이·나나)·캐릭터 적용, 링크 설치 + 앱 내 업데이트
2. 다음: 기념일 알림 → 음력 → 오늘의 질문
3. 그다음: 일정 카테고리 색, 공유 할 일·버킷리스트, 백업 내보내기
