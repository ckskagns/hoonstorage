# 데이트 통장 가계부: 토스 모임통장 카드 결제 자동 연동 검토 (2026-11-02)

## 결론

- **토스 서버에서 거래내역을 직접 받아오는 방법은 지금 쓸 수 없다.**
  - 토스·토스뱅크는 개인 개발자가 쓸 수 있는 거래내역 공개 API 가 없다.
  - 오픈뱅킹은 금융결제원과 계약한 사업자만 쓸 수 있다. 마이데이터는 허가 사업자만 쓸 수 있다.
- **현실적인 방법은 "폰에 오는 토스 결제 알림을 우리둘 앱이 읽어서 기록"하는 것이다.**
  - 모임카드로 누가 결제하든 모임원 모두에게 알림이 온다. 그래서 후이 폰·나나 폰 어느 쪽이든 받으면 기록된다.
  - 서버나 비용(무료 요금제) 문제 없이 지금 앱 구조로 만들 수 있다.
- 참고: 토스뱅크 앱 안에도 커플통장 "소비" 탭, "함께 쓰는 캘린더"의 가계부(모임통장 지출 자동 기록)가 있다. 우리둘의 장점은 **일정·후기·사진과 지출을 한 곳에서 묶어 보는 것**이다.

## 방법 비교

| 방법 | 자동? | 가능 여부 | 메모 |
|---|---|---|---|
| 토스/토스뱅크 공개 API | 자동 | ✗ | 개인용 공개 API 없음 |
| 오픈뱅킹 API (금융결제원) | 자동 | ✗ | 이용기관(사업자) 계약 + 보안 점검 필요 |
| 마이데이터 | 자동 | ✗ | 금융위 허가 사업자만 |
| **결제 알림 읽기** (안드로이드 알림 접근) | **자동** | **○** | 폰에서 직접 처리, 서버 불필요 |
| 문자(SMS) 읽기 | 자동 | △ | 토스뱅크 카드는 보통 푸시 알림만 와서 해당 없음 |
| 거래내역 파일 가져오기 | 반자동 | △ | 토스 앱의 내보내기 형식 확인 필요 (빠진 내역 채우기용) |
| 직접 입력 | 수동 | ○ | 알림을 놓친 경우·현금 결제용으로 함께 제공 |

## 알림 읽기 방식 설계 (제안)

1. **알림 받기**
   - 안드로이드 `NotificationListenerService` 를 쓴다.
   - 토스 앱 알림만 골라 본다(패키지 이름으로 거름). 다른 앱 알림은 읽지도 저장하지도 않는다.
2. **글 풀기**
   - "모임카드/모임통장 결제" 알림에서 금액, 가맹점, 시각, 결제한 사람(모임원 이름이 있으면)을 뽑는다.
   - 결제 취소·환불 알림은 마이너스로 기록한다.
3. **저장**
   - Firestore `couples/{id}/expenses/{문서ID}` 에 저장한다.
   - 문서ID 는 "시각(분)+금액+가맹점" 으로 만든다. 두 폰이 같은 알림을 받아도 하나만 남는다.
4. **가계부 화면**
   - 달별 합계와 날짜별 목록을 보여 준다.
   - 분류(식비·카페·교통·숙소·문화…)는 가맹점 이름으로 자동 추정하고, 고칠 수 있다.
   - 메모, 지우기, 직접 추가를 지원한다.
5. **우리둘다운 연결**
   - 결제한 날 일정이 있으면 그 일정 상세·일기장 게시물에 "이 날 쓴 돈 ₩38,000"을 보여 준다.
   - 데이트 하루 비용·달별 데이트비를 한눈에 본다.
6. **비용·용량**
   - 지출 한 건은 약 0.3KB 다. 하루 10건씩 3년이어도 약 3MB 라서 무료 요금제 안이다.

## 주의할 점

- **알림 접근 허용**: 각자 폰의 설정에서 "알림 접근 허용 → 우리둘"을 직접 켜야 한다. 이 권한은 폰의 모든 알림을 볼 수 있는 권한이라, 앱이 토스 알림만 처리한다는 점을 화면에 분명히 안내한다. 끄는 방법도 같은 메뉴다.
- **알림을 놓치면 기록도 빠진다**: 토스 알림을 꺼 두었거나, 두 폰 모두 꺼져 있었거나, 삼성 절전이 앱을 멈추면 빠질 수 있다. 직접 추가로 채운다. 나중에 파일 가져오기를 더할 수도 있다.
- **알림 문구가 바뀌면** 글 풀기를 고쳐야 한다. 실제 알림 문구 몇 개가 있어야 정확하게 만들 수 있다.
- **개인정보**: 금액·가맹점은 커플 공간에만 저장되고, 서버 규칙으로 두 사람만 볼 수 있게 한다.

## 진행에 필요한 것

- 실제 **토스 모임카드 결제 알림 문구** 2~3개 (결제·취소 각각, 금액·가게 이름은 가려도 됨).
  - 알림을 길게 눌러 보이는 글이나 캡처를 보내 주면 된다.
  - 개발자가 폰의 다른 알림을 읽지 않도록, 문구는 사용자가 직접 전달한다.
- 개발 범위 합의: 1차 = 알림 자동 기록 + 가계부 탭(달별 목록·합계·분류·직접 추가). 2차 = 일정/일기장 연결, 파일 가져오기.
