# AI 비서 검토·작업 보관 (2026-11-09, 롤백함)

> 요약: 우리둘에 "비서 AI"(청약·결혼 정보 검색 → 할 일 등록, 소비 패턴·저축 관리)를 붙이려고
> 제미나이와 Claude 를 차례로 검토·구현했지만, **완전 무료**로 쓸 방법이 없어 앱 코드·서버 규칙·클라우드 설정을 모두 되돌렸다.
> 다시 시작할 때 이 문서와 아래 커밋을 보면 된다.

## 1. 하려던 것

- 비서 AI: 청약·결혼 등 **최신 정보 검색** → 해야 할 일 등록(확인 카드), 가계부 **소비 패턴·저축** 정리
- 관리 기능(관리자 = 커플 공간을 만든 사람, 후이만): AI 켜기/끄기, API 키 넣기·보기·지우기, 연결 시험
- AI 를 끄면 앱이 AI 를 부르지 않고(요금 없음), 나나 폰은 서버 규칙으로 키도 받을 수 없게

## 2. 검토 결과 (무료 여부 중심)

| 방법 | 무료? | 검색 | 메모 |
|---|---|---|---|
| 제미나이 앱(Pro 구독)을 앱에서 직접 부르기 | — | — | **불가**: 다른 앱이 질문을 보내고 답을 받는 공개 기능 없음. "제미나이에게 보내기"(답은 제미나이 앱에 남음)만 가능 |
| 폰 안 Gemini Nano (ML Kit Prompt API) | **무료** | ✗ | 폴드8(nano-v4)·S26 울트라(nano-v3) 지원, 한국어 검증. 인터넷 검색·최신 정보 없음, 우리둘 화면이 앞에 있을 때만, 작은 모델 → 가계부 요약 정도만 적합 |
| 제미나이 API (구글 클라우드) | ✗ | ○ | 새 계정은 **선불 충전 필수(최소 $5)**, 무료 체험 결제 계정은 유료 등급 불가, $300 체험 크레딧은 제미나이에 못 씀. Pro 월 $10 크레딧이 쓰이는지는 문서에 없음. 무료 사용분은 하루 20회 수준·검색 연결 안 됨·대화가 학습에 쓰임 |
| Firebase AI Logic (Spark) | 무료 사용분만 | ✗ | 2026-11-02부터 App Check 필수 → 구글 플레이 밖 배포(우리둘)는 통과 어려움 |
| Claude API | ✗ (Max·Ultra·Team 플랜이면 월 크레딧) | ○ | 구독(Pro)과 API 결제는 별도. **Max $100·Ultra $200/월 API 크레딧 포함**(콘솔 카드 불필요, 다 쓰면 멈춤·청구 없음). Pro·Free 는 해당 없음 → 콘솔 선불 충전 필요. API 대화는 학습에 쓰이지 않음 |

요금 참고 (2026-11 공식 요금표, 100만 토큰당 입력/출력): Claude Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50, 웹 검색 $10/1,000회.
검색 질문 한 번 어림: Opus 약 100원, Sonnet 약 50원.

**결론**: 검색까지 되는 비서 AI 를 "완전 무료"로 쓸 방법은 없었다.
무료로 가능한 것은 폰 안 Gemini Nano(검색 없음)뿐 → 다시 할 때 1순위 후보 (가계부 요약·문장 다듬기 등).

설계 요점:
- 키는 공개 APK 에 넣지 않고 Firestore `aiConfig/assistant { enabled, apiKey }` 에 저장. 규칙: 관리자(멤버 첫 번째)만 쓰기, 상대는 `enabled == true` 일 때만 읽기
- 앱의 모든 AI 호출은 `AiService.ask` 한 곳을 거치고, 부를 때마다 서버에서 켜짐 여부를 확인
- 한 번 부를 때 답 길이 상한(4,096토큰)

## 4. 롤백한 것 (2026-11-09)

- 앱 코드: `ai/`, `ui/AdminDialog.kt`, 메뉴 "관리자 설정", `Couple.isAdmin`, 테스트 → 0.15.0 상태로

## 5. 남아 있는 것 (직접 정리 가능)

- 구글 클라우드 결제 계정 "내 결제 계정" (무료 체험, 카드 등록됨): 연결된 프로젝트가 없으면 청구 없음. 필요 없으면 콘솔 → 결제 → 계정 관리 → **결제 계정 닫기**
