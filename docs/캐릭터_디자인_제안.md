## 1. 그림 분석

### 1-1. 규격 — 앱에 바로 쓰기 좋음
| 항목 | 결과 |
|---|---|
| 크기·형식 | 27장 모두 1024×1024 PNG, 배경 투명(RGBA) |
| 여백 | 27장 모두 위 82px·아래 83px(각 8%)로 **똑같음** → 화면마다 키가 들쭉날쭉하지 않음 |
| 옆 여백 | 두 사람 그림 11~22%, 혼자 그림 28~29% |
| 가장자리 | 반투명 픽셀 1% 안팎 → 어떤 배경에 올려도 테두리 얼룩 없음 |
| 파일 크기 | 장당 0.36~0.85MB, 모두 16MB → 앱에 그대로 넣기엔 큼 (4장 참고) |

### 1-2. 그림체·색
- 2.5~3등신 손그림 커플 이모티콘체. 진한 갈색 외곽선, 볼 터치, 주변 분홍 하트, 감정마다 한글 손글씨 효과음(헤헤·꼬옥·쪽·두근…).
- 남: 검은 머리, **하늘색 맨투맨**, 검은 바지, 금색 용 뿔 머리띠. 여: 갈색 긴 머리, **복숭아빛 맨투맨**, 남색 치마, 토끼 귀 머리띠.
  → 앱의 아기 용(후이)·토끼(나나) 캐릭터와 그대로 이어짐.
- 많이 쓰인 색 (기본 그림 기준)

### 1-3. 작은 자리에서 얼굴 크기
얼굴(이마~턱)은 그림 높이의 약 18%. 그림을 92dp 로 넣으면 얼굴이 17dp 라 표정이 안 보인다.
→ **전신 그림은 130dp 이상**에서만, 그보다 작은 자리(아바타·벤토·카드 구석)는 **얼굴만 자른 그림**을 쓴다.

## 2. 앱 아이콘

지금: 분홍 바탕(`#FFD9E2`) 위 하트 하나.

| 시안 | 내용 | 48px 에서 | 평가 |
|---|---|---|---|
| A 꼬옥 | 껴안은 두 얼굴 | 얼굴이 붙어 뭉침, "꼬옥" 글씨가 얼룩처럼 | △ |
| B 두 얼굴 | 나란히 웃는 얼굴 | 두 사람은 보이나 특징이 약함 | ○ |
| **C 하트 쥔 두 얼굴** | 가운데 빨간 하트 + 두 얼굴 | **하트가 먼저 보여 바로 알아봄** | ◎ 추천 |
| C2 | C + 복숭아→하늘 바탕 | 바탕이 회색빛으로 탁해 보임 | △ |

추천 **C (분홍 바탕)**:
- 지금 아이콘의 "분홍 바탕 + 하트"를 그대로 이어 받아, 바뀌어도 홈 화면에서 찾기 쉽다.
- 적응형 아이콘 규격: 108dp 층 안에 얼굴 묶음을 74dp 폭으로, 원 모양에서도 뿔이 잘리지 않게 5dp 아래로.
- **테마 아이콘(단색)은 지금 하트 그대로** (그림을 단색으로 바꾸면 뭉개짐).
- 앱 시작 화면(안드로이드 12+ 스플래시)도 같은 아이콘이 크게 나오므로 자연스럽게 함께 바뀐다.
- 더 또렷하게 하려면: 제미나이에 "아이콘 전용" 한 장을 부탁 — *"이 두 캐릭터의 머리와 어깨만, 가운데 큰 빨간 하트를 둘이 함께 쥐고, 글씨·작은 하트 없이, 외곽선 1.5배 굵게, 정사각형 투명 배경"*.

## 3. 화면별 제안

### 3-1. 원칙 (지난 선호도 조사 결과와 맞춤)
1. **사진·내용이 주인공, 캐릭터는 감정을 거든다** — 한 화면에 큰 캐릭터는 하나만. 사진 카드가 있으면 캐릭터는 작은 얼굴로만.
2. **상황에 맞는 감정** — 같은 그림 반복 대신 시간·기념일·빈 화면 종류에 따라 바꿔 "살아 있는" 느낌.
3. **크기 규칙** — 전신 130dp 이상, 그보다 작으면 얼굴 그림 (1-3).
4. **다크 모드는 받침** — 캐릭터 뒤에 연분홍 동그란 받침(`#FFE6EC`, 가장자리 흐리게). 1-2 대비 문제 해결.
5. **글씨 겹치지 않기** — 그림에 이미 "꼬옥·쪽" 같은 손글씨가 있으니 바로 옆에 같은 말을 또 쓰지 않는다.

### 3-2. 어디에 어떤 그림
| 화면 | 지금 | 제안 |
|---|---|---|
| 홈 디데이 카드 (사진 없음/끔) | 아기 용·토끼 | 시간대: 아침 5~9시 좋은 아침 / 낮 기본 / 밤 22~5시 쿨쿨 (이미 연결됨) |
| 홈 디데이 카드 — 기념일 당일 | 같은 카드 | 100일 단위·주년·생일: 축하해 + 하트 터짐, 그 다음 날부터 평소대로 |
| 기념일 당일 첫 실행 | 없음 | 축하 창 한 번: "오늘 우리 100일이에요 🎉" + [100일 돌아보기]·[사진 남기기] |
| 이름 옆 동그라미 ("후이 ❤ 나나") | 용·토끼 머리 | 각자 얼굴 그림 (후이 혼자 V·나나 혼자 손인사에서 얼굴만) |
| 벤토 네 칸 | 글자만 | **비어 있는 칸에만** 오른쪽 아래 작은 그림: 다음 일정=가자, 가고 싶은 곳=출발, 사진=찰칵, 가계부=저축 |
| 오늘의 질문 카드·창 | 이미 "고민" 자리 있음 | 답 전 고민 → 상대만 답함 보고싶어(창가) → 둘 다 답함 사랑해 하트(+하트 터짐) |
| 후기 하트 5개 저장 | 하트 터짐 | + 사랑해 그림 잠깐 |
| 상대가 후기를 남김 (앱 안 알림) | 글자 | 고마워(꽃) 작은 그림 |
| 이달의 우리 카드 | 이미 "꼬옥" 자리 | 그대로 (공유 그림 PNG 에도 함께 들어감) |
| 빈 화면 | 캐릭터 + "기록 없어요" | 일기 피드=편지, 모아보기=셀카, 가계부=저금통, 가고 싶은 곳=캐리어(이미 연결된 자리), **캘린더 빈 날=가자 + [이 날 데이트 계획하기]** |
| 저장 실패·오류 창 | 글자 | 미안 그림 |
| 아침 9시 일정 알림 | 앱 아이콘 | 알림 큰 아이콘에 좋은 아침 얼굴 |
| 설정 › 프로필 캐릭터 고르기 | 용·토끼·SD 연인 등 | 맨 앞에 "우리 캐릭터 (남/여)" 추가 — 이름 옆 동그라미와 위젯에 쓰임 |
| 디데이 위젯 | 용·토끼 | 위젯 설정에서 "우리 캐릭터" 고르기 (기본 그림) |
| 로그인·초대 화면 | 아이콘 | 기본 그림 / 초대 받는 쪽은 두근 |

### 3-3. 일정 색 = 옷 색
캐릭터 옷 색을 일정 색 **기본값**으로: 후이 = `sky`, 나나 = `peach`, 둘이 함께 = 분홍.
- 앱에 이미 있는 색 이름이라 서버 규칙 변경 없음, 이미 고른 사람의 색은 그대로.
- 이름 옆 얼굴 동그라미 테두리도 같은 색 → 누구 일정인지 그림과 색이 함께 알려 줌.

## 4. 넣는 방법 (기술)

- **크기 줄이기**: 1024 PNG 27장 = 16MB. 512px 로 줄이고 WebP(손실 90%)로 바꾸면 장당 약 30~60KB, 모두 1~1.5MB 예상.
  WebP 변환 도구 `cwebp`(Google, BSD 라이선스 — 상용 무료) 또는 안드로이드 스튜디오 내장 변환.
- **얼굴 그림 자동 생성**: 넣기 스크립트가 아바타용 얼굴(후이·나나), 아이콘용 묶음을 같이 잘라 만든다.
- **이름 바로잡기**: 넣기 스크립트에 1-4 표를 넣어 받은 파일 그대로 넣어도 맞는 이름으로 복사.
- 앱 코드(`ui/EmotionArt.kt`)는 파일만 있으면 자동으로 바뀌므로 이미 연결된 6곳(홈 낮·아침·밤, 이달의 우리, 빈 화면 5종, 오늘의 질문)은 수정 없이 바로 보인다.
- ⚠️ **저장소가 공개(GitHub)** 라서 앱 리소스로 넣으면 그림도 공개된다. 나나 사진을 바탕으로 만든 그림이므로 넣기 전에 확인 필요.
  (대안: 그림은 저장소에 올리지 않고 빌드할 때만 `assets_in` 에서 넣기 — `.gitignore` 로 제외)
