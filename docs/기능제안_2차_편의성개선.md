## 1. 이번 조사에서 새로 확인한 것

| 흐름 | 내용 | 우리둘에 주는 뜻 |
|---|---|---|
| **데이터 유실은 신뢰를 한 번에 무너뜨림** | 2026년 6월 비트윈에서 사진이 대량으로 지워졌고, 이용자에게 알리지 않아 반발이 컸음 | 지운 일정 되돌리기·백업이 "있으면 좋은 것"이 아니라 기본기 |
| **"둘 다 답해야 열리는" 질문이 여전히 핵심** | 썸원, LoveWidgets, Paired 모두 매일 질문 → 각자 답 → 함께 공개 구조 | 1차 제안의 "오늘의 질문"이 계속 유효 |
| **함께 가고 싶은 곳 목록(버킷리스트)** | TrueThings(데이트 아이디어 + 공유 버킷리스트), Couple2 "사랑의 목록", Couply(데이트 아이디어 → 둘의 달력에 바로 넣기) | 우리둘에는 이미 **지도 앱 공유로 장소 담기**가 있어서 적은 작업으로 만들 수 있음 |
| **위젯이 앱의 얼굴** | Cupla 위젯은 내 일정/둘의 일정 전환, Locket은 위젯에서 바로 사진 답장, LoveWidgets는 상대 홈 화면에 그림 보내기 | 위젯을 "보기"에서 "주고받기"로 넓힐 여지 |
| **잠금 화면 실시간 진행 표시** | 안드로이드 16 "실시간 업데이트"(Live Updates)를 One UI 8 Now Bar가 보여줌. 다만 다른 회사 앱 지원은 아직 제한적이라는 보도 | 데이트 당일 "저녁식사까지 40분" 같은 표시. 폴드8에서 실제로 보이는지 먼저 확인 필요 |
| **폴드 화면 활용** | 삼성 개발자 안내: 커버 화면 위젯 목록, 반쯤 접은 모드(Flex)에서 위·아래 나눠 쓰기 | 펼친 화면에서 달력 + 하루 일정을 한 화면에 |
| **상대 알림은 무료 요금제의 벽** | 푸시 알림 전달(FCM)은 무료지만, 보내는 쪽 서버(Cloud Functions)는 유료(Blaze) 요금제 필요 | 실시간은 유료. 대신 **폰이 15분마다 확인하는 방식**이면 무료로 가능 (아래 C-4) |

## 2. 지금 우리둘에 없는 것 (코드 확인)

- 공휴일 표시 없음 (기념일·생일만 있음)
- 반복 일정 없음 (매주·매달·매년)
- 일정 검색 없음 (시그널링에서 옮긴 39개 + 계속 늘어남)
- 일정을 지우면 바로 사라짐 (되돌리기·휴지통 없음)
- 상대가 일정을 추가·수정해도 알림 없음
- 음력 날짜 없음 (README 3단계 계획)

## 3. 제안 목록

난이도: 하(반나절) · 중(1~2일) · 상(3일 이상) / 비용: 모두 **현재 무료 요금제**로 가능한지 표시

### A. 매일 쓰기 편해지는 개선

| 우선 | 기능 | 내용 | 난이도 | 무료 |
|---|---|---|---|---|
| ★1 | **공휴일·대체공휴일 표시** | 달력·위젯 날짜를 빨갛게, 아래에 "추석" 같은 이름. 설·추석(음력)도 날짜 표로 미리 넣어 둠(2026~2030). 데이트·여행 계획에 바로 쓰임 | 하 | ○ |
| ★2 | **반복 일정** | 매주 / 매달(예: 매달 14일 데이트) / 매년. 하루 페이지에서 "반복" 선택. 이번 일정만 / 앞으로 모두 수정 | 중 | ○ |
| ★3 | **일정 검색** | 제목·장소·메모로 찾기. "선릉감자탕 언제 갔지?" | 하 | ○ |
| 4 | **알림 시간 고르기** | 지금은 30분 전 고정 → 10분 / 30분 / 1시간 / 하루 전 / 끄기를 일정마다 | 하 | ○ |
| 5 | **일정 복사·다른 날로 옮기기** | 일정을 길게 눌러 "복사", "날짜 옮기기". 비슷한 데이트를 다시 잡을 때 | 하 | ○ |
| 6 | **준비물 체크리스트** | 일정 안에 체크 목록(여행 짐, 예약 확인 등). 둘이 같이 체크 | 중 | ○ |

### B. 안심하고 쓰기 (데이터 지키기)

| 우선 | 기능 | 내용 | 난이도 | 무료 |
|---|---|---|---|---|
| ★1 | **지운 일정 되돌리기** | 지우면 아래에 "되돌리기" 버튼(5초). 추가로 "최근 지운 일정" 30일 보관 후 정리 | 하 | ○ |
| ★2 | **백업 파일 저장·불러오기** | 일정·기념일·설정을 파일 하나로 폰에 저장, 다른 폰에서 불러오기 | 하 | ○ |
| 3 | **누가 바꿨는지 표시** | 일정 카드에 "나나가 어제 수정" (이미 저장 중인 수정자 정보 활용) | 하 | ○ |

### C. 둘이 함께 쓰는 재미

| 우선 | 기능 | 내용 | 난이도 | 무료 |
|---|---|---|---|---|
| ★1 | **가고 싶은 곳 목록** | 네이버·카카오·구글 지도에서 우리둘로 공유하면 "가고 싶은 곳"에 저장 (지금 있는 장소 공유 기능 재사용). 하나를 골라 "이날 가자" → 바로 일정이 됨. 다녀오면 ✓ | 중 | ○ |
| ★2 | **오늘의 질문** | 하루 한 질문, 둘 다 답해야 서로의 답이 열림. 질문 300개 앱 안에 내장, 지난 답 모아 보기 | 중 | ○ |
| 3 | **오늘의 기분** | 이모지 하나로 기분 공유, 하트·디데이 위젯에 상대 기분 표시 | 하 | ○ |
| 4 | **상대 활동 알림 (무료 방식)** | 폰이 약 15분마다 서버를 확인해서 "나나가 11/2 일정을 추가했어요" 알림. 실시간은 아니지만 배터리 부담 적음. 즉시 알림은 유료 요금제(사용량이 적어 실제 요금은 거의 0원) | 중 | ○ |
| 5 | **위젯 콕 찌르기** | 하트 위젯을 누르면 상대 위젯의 하트가 콩닥 + 알림. C-4와 같은 방식이라 최대 15분 늦게 도착 | 중 | ○ |

### D. 추억 쌓기

| 우선 | 기능 | 내용 | 난이도 | 무료 |
|---|---|---|---|---|
| 1 | **데이트 한 줄 후기** | 지난 일정에 한 줄 메모 + 하트 1~5개. 장소별로 "또 가고 싶은 곳" 모아 보기 | 하 | ○ |
| 2 | **작년 오늘** | 홈에 "1년 전 오늘: 성수 데이트" 카드 (시그널링 기록이 2026-07부터라 내년 여름부터 의미) | 하 | ○ |
| 3 | 일정 사진첩 | 보류했던 기능. 원본 사진 저장은 유료 요금제(Storage) 필요, 작은 사진만이면 무료 — [사진 기능 검토](사진기능_도입검토.md) | 상 | △ |

### E. 폴드8 · S26 Ultra 활용

| 우선 | 기능 | 내용 | 난이도 | 무료 |
|---|---|---|---|---|
| 1 | **펼친 화면 2단** | 왼쪽 달력 / 오른쪽 그날 타임라인. 날짜를 누르면 오른쪽만 바뀜 (지금은 전체 화면 페이지로 넘어감) | 중 | ○ |
| 2 | **잠금 화면 데이트 진행 표시** | 데이트 당일 Now Bar에 "저녁식사 18:30 · 40분 남음". 폴드8 One UI 버전에서 다른 회사 앱 표시가 되는지 먼저 시험 | 중 | ○ |
| 3 | 커버 화면 위젯 점검 | 커버 화면 위젯 목록에 우리둘이 나오는지, 글씨 크기 확인 (1차 조사에서 시그널링 "폴드에서 위젯 글씨 작음" 불만) | 하 | ○ |

### F. 음력 (기존 3단계 계획)

| 기능 | 내용 | 난이도 |
|---|---|---|
| 음력 기념일·일정 | 부모님 생신 등 음력으로 매년 반복. 안드로이드 내장 음력 계산(ICU)을 쓰되, 한국 음력과 날짜가 맞는지 2026~2030 설·추석 표로 검증 후 적용 | 중 |

### 계속 추천하지 않음
- 실시간 위치 공유: 배터리·사생활 부담, 리뷰 불만 1순위
- 채팅: 카카오톡으로 충분
- 광고·유료 기능: 두 사람 전용 앱
