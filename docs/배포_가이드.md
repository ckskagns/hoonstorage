# 우리둘 배포·업데이트 가이드

플레이 스토어 없이 두 사람에게만 앱을 배포하고, 이후 새 버전을 앱 안에서 업데이트하는 방법입니다.

## 구조

| 무엇 | 어디에 | 주소 |
|---|---|---|
| 설치 안내 페이지 | Firebase Hosting | https://rabbithooni-5d8f4.web.app/download/ |
| 최신 버전 정보 (`version.json`) | Firebase Hosting | https://rabbithooni-5d8f4.web.app/download/version.json |
| 앱 파일 (APK) | GitHub Releases | https://github.com/ckskagns/hoonstorage/releases |
| 초대 링크 | Firebase Hosting | https://rabbithooni-5d8f4.web.app/invite/... |

- Firebase 무료(Spark) 요금제는 APK 같은 실행 파일을 올릴 수 없어서, APK 만 GitHub Releases 에 둡니다.
- 앱은 열릴 때마다 `version.json` 을 확인하고, 더 새 버전이면 "새 버전이 있어요" 창을 띄웁니다.
- 업데이트는 APK 를 내려받은 뒤 SHA-256 으로 파일이 맞는지 검사하고 안드로이드 설치 화면을 엽니다.

## 새 버전 배포 (내 PC 에서)

```powershell
powershell -ExecutionPolicy Bypass -File D:\APP_TEST\scripts\release.ps1 -Notes "이번에 바뀐 내용"
```

- 버전을 지정하려면 `-Version 0.4.0`, 버전을 그대로 다시 올리려면 `-NoBump` 를 붙입니다.
- 스크립트가 버전 올리기 → 빌드 → GitHub Releases 업로드 → `version.json` 배포까지 합니다.
- 배포 후 코드 변경(버전 번호 포함)은 평소처럼 GitHub 에 커밋합니다.

**처음 한 번만 필요한 준비**: GitHub CLI 로그인 (2026-10-27 완료)

```powershell
$env:GH_CONFIG_DIR = "$env:USERPROFILE\.config\gh"; & "C:\Program Files\GitHub CLI\gh.exe" auth login --hostname github.com --git-protocol https --web
```

## 여자친구 폰(S26 Ultra) 처음 설치

1. 앱에서 **초대 링크 보내기** → 카카오톡으로 전달
2. 여자친구가 링크를 누름 → 앱이 없으면 **"앱이 아직 없어요 · 설치하기"** → 설치 페이지
3. **앱 내려받기** → 다운로드한 `uridul.apk` 열기
4. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용** 켜고 돌아와 **설치**
   - 설치가 막히면 **설정 → 보안 및 개인정보 보호 → 자동 차단**을 잠시 끄고 설치 (설치 후 다시 켜도 됨)
   - **Google Play 프로텍트** 안내가 나오면 "앱 검사"(구글에 파일을 보내 검사) 또는 "자세히 → 검사 없이 설치" 중 선택
5. 설치 후 **초대 링크를 다시 눌러** 연결 → 자동으로 "나나 · 토끼" 로 설정됨

## 이후 업데이트 (두 사람 폰)

1. 앱을 열면 **"새 버전이 있어요"** → **업데이트**
2. 처음 한 번은 **"설치 허용이 한 번 필요해요"** → **허용하러 가기** → 우리둘의 **이 출처 허용** 켜고 뒤로
3. 자동으로 내려받기 → 설치 화면에서 **업데이트**
4. 일정·기록은 그대로 남습니다 (서버에 저장되어 있음)

메뉴의 **업데이트 확인**으로 직접 확인할 수도 있습니다.

## 꼭 지킬 것

- **서명 키 백업**: 업데이트는 같은 서명 키로 만든 APK 만 설치됩니다.
  `C:\Users\chanamhoon\.android\debug.keystore` 를 USB·클라우드 등 다른 곳에 백업해 두세요.
  이 파일을 잃어버리면 두 폰 모두 앱을 지우고 다시 설치해야 합니다 (데이터는 서버에 남음).
- `versionCode` 는 항상 커져야 합니다 (스크립트가 자동으로 +1).
